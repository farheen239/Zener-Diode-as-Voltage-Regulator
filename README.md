# Zener-Diode-as-Voltage-Regulator'
This project demonstrates the use of a Zener diode as a voltage regulator to maintain a constant output voltage under varying input voltages (line regulation) and different load conditions (load regulation). The setup includes a Zener diode in reverse bias with a series resistor, connected on a breadboard or PCB using jumper wires. A variable power supply is used to change the input voltage, and different load resistors simulate load changes. A multimeter measures both input and output voltages to observe regulation performance. The Zener diode ensures the output voltage remains stable, highlighting its role as a simple yet effective voltage regulator.
